# テストケース — PDT-1107: シーズン一覧タブ絞り込み修正

**対象環境:** Stage管理画面
**前提条件:** 管理画面にログイン済みであること。本編・制作裏側の両タイプのシーズンが存在するWorkがあること。

---

## TC-01: バグ再現経路（Work一覧 → シーズン一覧）での「本編」タブ絞り込み

**目的:** バグが発生していた遷移経路（Work一覧からシーズン一覧へ移動）において、「本編」タブが正しく機能することを確認する
**経路:** サイドメニュー → Work一覧 → 対象Workの行をクリック → シーズン一覧

手順:
1. サイドメニューから「Work」をクリックし、Work一覧画面を開く
2. 本編・制作裏側の両シーズンが存在するWorkの行をクリックし、そのWorkのシーズン一覧画面に遷移する
3. シーズン一覧画面上部に「すべて」「本編」「制作裏側」のタブが表示されていることを確認する
4. 「本編」タブをクリックする
5. 表示されているシーズン一覧を確認する

期待結果:
- タイプが「本編」のシーズンのみが一覧に表示される
- タイプが「制作裏側」のシーズンは一覧に表示されない
- 「本編」タブがアクティブな状態（選択中）で表示される
- （旧バグ）タブクリック後に全件が表示されたままになることはない

## TC-04: タブ絞り込み後のページネーション維持

**目的:** 「本編」または「制作裏側」タブで絞り込んだ状態でページネーションを操作しても、フィルターが維持されることを確認する
**経路:** サイドメニュー → Work一覧 → 対象Workの行をクリック → シーズン一覧

前提条件（追加）: 「本編」または「制作裏側」のどちらか一方のタイプのシーズンが、1ページに収まらない件数（ページネーションが発生する件数）存在するWorkを使用すること。

手順:
1. サイドメニューから「Work」をクリックし、Work一覧画面を開く
2. 対象Workの行をクリックし、そのWorkのシーズン一覧画面に遷移する
3. 「本編」タブをクリックし、本編シーズンのみが表示されていることを確認する
4. ページネーションの「次へ」ボタン（または2ページ目のリンク）をクリックする
5. 表示内容を確認する
6. ページネーションの「前へ」ボタン（または1ページ目のリンク）をクリックして戻り、表示内容を確認する

期待結果:
- 手順4実施後（2ページ目）: 「本編」タブがアクティブなままで、タイプが「本編」のシーズンのみが表示される。「制作裏側」のシーズンは表示されない
- 手順6実施後（1ページ目）: 「本編」タブがアクティブなままで、タイプが「本編」のシーズンのみが表示される
- ページ移動によってタブの絞り込みが解除されることはない

## TC-05: URL直接アクセス時の初期表示（リグレッション確認）

**目的:** WorkのシーズンページURLに直接アクセスした場合、初回表示で「すべて」タブがデフォルト選択となりすべてのシーズンが表示されることを確認する（リグレッションなし）
**経路:** ブラウザのアドレスバーから直接URLを入力してアクセス

手順:
1. 対象WorkのシーズンページのURLをブラウザのアドレスバーに直接入力し、Enterキーを押す（例: `/works/{workId}/seasons`）
2. ページが読み込まれた後、タブの選択状態と一覧を確認する

期待結果:
- 「すべて」タブがアクティブ（デフォルト選択）の状態でページが表示される
- 本編・制作裏側の両タイプのシーズンがすべて一覧に表示される
- 特定タイプのみに絞り込まれた状態でページが表示されることはない

## TC-07: ブラウザの「戻る」ボタンでWork一覧に戻った後の再アクセス（リグレッション確認）

**目的:** シーズン一覧でタブを切り替えた後、ブラウザの「戻る」で前の画面に戻り、再度シーズン一覧に遷移した際に初期状態が正しく表示されることを確認する
**経路:** サイドメニュー → Work一覧 → シーズン一覧 → ブラウザ「戻る」 → 再度シーズン一覧

手順:
1. サイドメニューから「Work」をクリックし、Work一覧画面を開く
2. 対象Workの行をクリックし、そのWorkのシーズン一覧画面に遷移する
3. 「本編」タブをクリックし、本編シーズンのみが表示されていることを確認する
4. ブラウザの「戻る」ボタンをクリックしてWork一覧画面に戻る
5. 同じWorkの行をクリックし、シーズン一覧画面に再度遷移する
6. 表示内容を確認する

期待結果:
- 手順6実施後: 「すべて」タブがアクティブな状態でページが表示されるか、または前回選択したタブ（本編）が引き続き選択された状態で正しい絞り込み結果が表示される
- 手順6実施後: タブ選択状態と表示内容が一致しており、全件が表示されているのにタブが「本編」を示すといった不整合は発生しない
