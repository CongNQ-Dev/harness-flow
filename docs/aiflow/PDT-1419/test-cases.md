### TC-01: 新規作成画面初期ロード時にシーズン登録エリアが非表示であること

**テストケース番号:** TC-01  
**目的:** バグ修正の確認。新規作成画面の初期状態でシーズン登録エリア（シーズンドロップダウンと画像アップロード行）が表示されていないことを確認する。

**前提条件:**
- 管理画面にログイン済みであること
- 全話無料キャンペーン（カウントダウン）の一覧画面にアクセスできること

**手順:**
1. 管理画面にログインする
2. 左メニューまたはナビゲーションから「全話無料キャンペーン（カウントダウン）」一覧画面に遷移する
3. 一覧画面右上の「新規作成」ボタンをクリックする
4. 新規作成画面 `/segment-season-free-promo-create` が表示されることを確認する
5. ページを最下部までスクロールし、「シーズン」セクション付近を確認する
6. ブラウザの開発者ツール（F12）は使用せず、画面上の表示状態のみを確認する

**期待結果:**
- 新規作成画面の初期ロード時、シーズン選択ドロップダウン・画像アップロードフィールドを含むシーズン行が **0件（何も表示されない）** であること
- 「シーズンを追加」ボタンのみが表示されており、その下にシーズン行が自動で表示されていないこと

### TC-02: 「シーズンを追加」ボタン押下でシーズン行が1件追加されること

**テストケース番号:** TC-02  
**目的:** 「シーズンを追加」ボタンを押したときに、シーズン登録行が正しく1件追加されることを確認する。

**前提条件:**
- 管理画面にログイン済みであること
- 全話無料キャンペーン新規作成画面 `/segment-season-free-promo-create` が表示されていること
- TC-01 の確認が完了しており、初期状態でシーズン行が0件であることが確認済みであること

**手順:**
1. 全話無料キャンペーン新規作成画面 `/segment-season-free-promo-create` を開く
2. ページを最下部までスクロールし、シーズンセクションを表示する
3. 初期状態でシーズン行が0件であることを目視確認する
4. 「シーズンを追加」ボタンをクリックする
5. 画面の変化を確認する

**期待結果:**
- 「シーズンを追加」ボタンをクリック後、シーズン選択ドロップダウンおよび画像アップロードフィールドを含むシーズン行が **1件** 表示されること
- 追加されたシーズン行は空の状態（未選択・未入力）であること
- シーズン行に「削除」ボタンまたは削除アイコンが表示されること（行の削除が可能な状態であること）

### TC-03: 「シーズンを追加」ボタンを複数回押下すると行が複数件追加されること

**テストケース番号:** TC-03  
**目的:** 「シーズンを追加」ボタンを複数回押したときに、押した回数分だけシーズン行が正しく追加されることを確認する。

**前提条件:**
- 管理画面にログイン済みであること
- 全話無料キャンペーン新規作成画面 `/segment-season-free-promo-create` が表示されていること

**手順:**
1. 全話無料キャンペーン新規作成画面 `/segment-season-free-promo-create` を開く
2. ページを最下部までスクロールし、シーズンセクションを表示する
3. 「シーズンを追加」ボタンを1回クリックし、行が1件追加されることを確認する
4. さらに「シーズンを追加」ボタンをクリックし、合計2件の行が表示されることを確認する
5. さらに「シーズンを追加」ボタンをクリックし、合計3件の行が表示されることを確認する

**期待結果:**
- 「シーズンを追加」ボタンを押すたびに、シーズン行が1件ずつ下に追加されること
- 3回押した時点で、シーズン行が合計 **3件** 表示されること
- 各行はそれぞれ独立しており、選択・入力内容が互いに影響しないこと

### TC-04: 追加したシーズン行を削除できること

**テストケース番号:** TC-04  
**目的:** 追加したシーズン行の削除ボタンが機能することを確認する。

**前提条件:**
- 管理画面にログイン済みであること
- 全話無料キャンペーン新規作成画面 `/segment-season-free-promo-create` が表示されていること
- 「シーズンを追加」ボタン押下で2件以上のシーズン行が追加済みであること

**手順:**
1. 全話無料キャンペーン新規作成画面 `/segment-season-free-promo-create` を開く
2. 「シーズンを追加」ボタンを2回クリックし、シーズン行を2件追加する
3. 2件のシーズン行が表示されていることを確認する
4. 1件目のシーズン行にある「削除」ボタン（またはゴミ箱アイコン）をクリックする
5. 画面の変化を確認する

**期待結果:**
- 1件目のシーズン行が削除され、残り **1件** のみ表示されること
- 残った行の表示・入力内容に影響がないこと
- シーズン行が1件のみの場合、削除ボタンの表示状態を確認する（仕様に応じて非表示または無効化されること）

### TC-05: 編集画面を開くと既存のシーズン行が正しく表示されること

**テストケース番号:** TC-05  
**目的:** リグレッション確認。既存の全話無料キャンペーンの編集画面を開いたとき、登録済みのシーズン行が正しく読み込まれて表示されることを確認する。

**前提条件:**
- 管理画面にログイン済みであること
- シーズン行が1件以上登録済みの全話無料キャンペーン（カウントダウン）データが存在すること
- 対象データのIDまたは編集画面URLが確認できること

**手順:**
1. 全話無料キャンペーン（カウントダウン）一覧画面に遷移する
2. シーズン行が登録済みの既存データの「編集」ボタンをクリックする
3. 編集画面（`/segment-season-free-promo-edit/[id]` など）が表示されることを確認する
4. ページを最下部までスクロールし、シーズンセクションを確認する
5. 表示されているシーズン行の件数・内容を確認する

**期待結果:**
- 編集画面のシーズンセクションに、登録済みのシーズン行が **正しい件数・正しい内容** で表示されること
- 各シーズン行のシーズン選択ドロップダウン・画像フィールドに、登録済みのデータが正しく表示されること
- 編集画面を開いた直後に空の行が自動追加されていないこと

### TC-06: 編集画面で既存データを保存しても内容が変わらないこと

**テストケース番号:** TC-06  
**目的:** リグレッション確認。編集画面で何も変更せずに保存した場合、シーズン行のデータが変わらないことを確認する。

**前提条件:**
- 管理画面にログイン済みであること
- シーズン行が1件以上登録済みの全話無料キャンペーン（カウントダウン）データが存在すること
- 保存前の登録内容（シーズン数・シーズンID・画像）を事前にメモしておくこと

**手順:**
1. 全話無料キャンペーン（カウントダウン）一覧画面に遷移する
2. 対象の既存データの「編集」ボタンをクリックし、編集画面を開く
3. 編集画面で表示されているシーズン行の件数・シーズン名・画像を確認し、内容をメモする
4. **何も変更せず**「保存」ボタンをクリックする
5. 保存成功のメッセージまたは一覧画面への遷移を確認する
6. 再度同じデータの編集画面を開き、シーズンセクションを確認する

**期待結果:**
- 保存後に再度編集画面を開いた際、シーズン行の件数・シーズン選択・画像内容が保存前とまったく同じであること
- データが意図せず削除・変更されていないこと

### TC-07: 新規作成画面でシーズンを追加せずに保存した際の動作確認

**テストケース番号:** TC-07  
**目的:** エッジケース確認。新規作成画面でシーズン行を1件も追加しない状態でフォームを送信した際の動作を確認する。

**前提条件:**
- 管理画面にログイン済みであること
- 全話無料キャンペーン新規作成画面 `/segment-season-free-promo-create` が表示されていること
- キャンペーン名など、シーズン行以外の必須項目を入力済みであること

**手順:**
1. 全話無料キャンペーン新規作成画面 `/segment-season-free-promo-create` を開く
2. シーズン行を一切追加せずに（「シーズンを追加」ボタンを押さずに）、その他の必須項目を入力する
3. 「保存」ボタンをクリックする
4. 画面の反応・エラーメッセージ・ダイアログを確認する

**期待結果:**
- シーズン行が0件の状態でも、フォームが正常に送信されるか、または適切なバリデーションエラーが表示されること
- 画面がクラッシュしたり予期しない挙動にならないこと
- ユーザーに対して適切なフィードバック（成功メッセージまたはエラーメッセージ）が表示されること
